# Recipe AI — Assets de plantilla

Incluye los recursos base para implementar el diseño moderno del sitio Recipe AI.

## Archivos

- `mockup/recipe-ai-ui-mockup.png`: imagen de referencia del diseño final.
- `styles/recipe-ai-tokens.css`: paleta, sombras, bordes, estilos base y clases reutilizables.
- `components/RecipeAI.jsx`: componente React/Tailwind listo para adaptar en tu proyecto.
- `icons/*.svg`: íconos SVG simples para usar como assets.

Usa la paleta cálida crema/naranja/café, cards glassmorphism, navbar, hero, formulario con chips de ingredientes, botón con gradiente, panel de receta con secciones y feature row inferior.
